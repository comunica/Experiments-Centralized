How to read this report
Template time
For WatDiv and LDBC SNB, the mean over all executions of a template's queries (every query runs several times after a warm-up round). For BSBM, the driver's geometric mean per query type. Whiskers span the fastest and slowest execution.
Geometric mean
The geometric mean of the template times over the templates that every engine of that run answered without a failure or an invalid result, so all engines are compared on the same templates. Sum of means uses the same templates.
The geometric mean of the per-template ratios to the reference engine, over the templates both engines answered (Shared). Below 1 means faster than the reference. This stays meaningful when engines fail on different templates.
Failed
Queries that returned an error or timed out (BSBM: timeouts reported by its driver).
Invalid
Queries whose result count differs from the count that a strict majority of the engines returned for the same query, among the engines that answered it without an error. A template with invalid results counts as not answered, like a failure. Counts are compared rather than the results themselves, as engines write equal values differently. BSBM's driver only reports an average count per query type, so a type is checked as a whole, and its DESCRIBE and CONSTRUCT types (Q9 and Q12) are not checked, as their result sizes differ by engine.
Startup and ingestion
Startup is the time from starting an endpoint until it answers, including loading the data. Ingestion is the time an engine reports for loading the data itself, without its startup or warm-up (for Comunica, from opening the dataset until it can be queried). Comunica-HDT's HDT file is created before the run, so its ingestion only opens that file.
Store size
What the loaded dataset takes where the engine keeps it: in memory for in-memory engines, and on disk (allocated space) for the others. Memory and disk sizes are not directly comparable, as engines can compress on disk and use formats that are slower to read. The repository's README lists how each engine measures it.
Scaling
When an experiment has runs at several scales, the scaling chart shows each engine's ratio to the reference per scale. The templates every engine answered can differ per scale.
